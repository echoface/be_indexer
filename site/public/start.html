02 · Schema：两个正交轴

IndexType 决定 posting 的索引结构；Encoder 决定字段值如何变成 term。没有明确理由时，先用 default。

goschema
import (
    be_indexer "github.com/echoface/be_indexer"
    // 可选容器需要 side-effect import：
    _ "github.com/echoface/be_indexer/container/fst"
    _ "github.com/echoface/be_indexer/container/mph"
    _ "github.com/echoface/be_indexer/container/geo"
)

fields := be_indexer.Schema{
    "age":     {IndexType: be_indexer.IndexNameExtendRange,
                Encoder:   be_indexer.IndexNameExtendRange},
    "city":    {IndexType: be_indexer.IndexNameDefault,
                Encoder:   "default"},
    "keyword": {IndexType: be_indexer.IndexNameACMatcher,
                Encoder:   be_indexer.IndexNameACMatcher},
}
业务需求IndexTypeEncoder
精确等值 / IN / NOT IN，词表 ≤ ~1Mdefaultdefault / number
超大高熵 key（设备号、UUID、hash）mph_dictdefault / number
超大结构化 key（URL、路径）fst_dictdefault
文本中筛多个关键词ac_matcherac_matcher
数值区间（>、<、Between）ext_rangeext_range
经纬度半径覆盖defaultproximitygeo
!

Schema 是索引身份的一部分。改字段名、IndexType 或 Encoder 都必须重新全量构建；delta 只能追加在同一 schema 下，否则 OpenIndex 会以 schema hash mismatch 拒绝加载。

03 · 规则建模：DNF 的三个硬约束

正确写法valid
doc := be_indexer.NewDocument(1).AddConjunction(
  be_indexer.NewConjunction().
    Between("age", 18, 25).
    In("city", be_indexer.NewStrValues("beijing")).
    NotIn("city", be_indexer.NewStrValues("rural")),
)
常见错误rejected
  • ×同一字段两个 Include：In("city", "bj") + In("city", "sh")。应合并为一个 Constraint。
  • ×同字段区间叠加：>18 + <35。应写 Between(19, 34)。
  • ×指望 Exclude 表达“字段缺失即不匹配”。字段缺失时没有游标，Exclude 不生效。

K 与通配

  • K = Include 字段数。查询必须同时提供这 K 个字段，Conjunction 才可能命中。
  • K=0 的纯 Exclude Conjunction 仍产生 wildcard 候选，但命中的 Exclude 能否决它。
  • 空 NewConjunction() 才是无条件规则。
  • DocID 更新用同一 ID + 新 Version，不要换新 DocID；删除用 Delete tombstone。
硬限制范围
DocID[-(2^43−1), 2^43−1]
单 Document 的 Conjunction 数< 256
K（单 Conjunction Include 数）< 256
全量构建内 DocID必须唯一

04 · 单段构建与查询

gobuild → load → query
import "github.com/echoface/be_indexer"

docs := []*be_indexer.Document{
    be_indexer.NewDocument(1).AddConjunction(
        be_indexer.NewConjunction().
            Between("age", 18, 25).
            In("city", be_indexer.NewStrValues("beijing")),
    ),
    be_indexer.NewDocument(2).AddConjunction(
        be_indexer.NewConjunction().
            NotIn("city", be_indexer.NewStrValues("rural")),
    ),
}

// 1. Build
var buf bytes.Buffer
if err := be_indexer.BuildSegment(&buf, fields, docs,
    be_indexer.BuildSegmentOptions{}); err != nil {
    return err
}

// 2. Load
reader, err := be_indexer.NewSegmentReader(buf.Bytes())
if err != nil { return err }
defer reader.Close()

engine, err := be_indexer.NewEngine(
    fields, []*be_indexer.SegmentReader{reader})
if err != nil { return err }
defer engine.Close()

// 3. Query
res, err := engine.Retrieve(be_indexer.Assignments{
    "age":  []int{20},
    "city": []string{"beijing"},
})
// res → *BitmapDocSet; DocID 1 与 2 命中

复用 collector，减少分配

goper-worker collector
collector := be_indexer.NewDocIDCollector() // 每个 worker 一个
collector.Reset()                           // 每次查询前重置

if err := engine.RetrieveWithCollector(query, collector); err != nil {
    return err
}
collector.Bitmap().ForEach(func(id be_indexer.DocID) {
    // 注意：Bitmap() 是借用视图，Reset 后会变化。
})

// 需要长期持有时：
owned := collector.Bitmap().Clone()
i

未知字段会被静默忽略。业务入口应按 Schema 白名单过滤字段名，避免上游拼错导致“静默漏召回”。数据质量要求高时用 WithStrictQuery()。

05 · 生产路径：full + delta

推荐一个 full 加一个累计 delta。每轮 delta 覆盖当前 full 截止位置之后的全部变更，发布时替换旧 delta；一个 full 或 delta 都可以包含多个 segment。

Result = (Full − Changed) ∪ (Delta − Deleted)

Full build

godaily full
full, err := be_indexer.NewFullIndexBuilder(be_indexer.FullIndexBuildOptions{
    Root:              "/data/index",
    Generation:        20240701,
    SnapshotWatermark: 100,
    Fields:            fields,
    Options: be_indexer.BuildDirectoryOptions{
        MaxDocsPerSegment:       5_000_000,
        MaxDistinctKeysInMemory: 2_000_000,
        MaxWildcardEntriesInMemory: 1_000_000,
    },
    FailMode: builder.FailFast,
})
if err != nil { return err }
defer full.Close()

for _, doc := range docs {
    if err := full.AddDocument(doc); err != nil {
        return err // FailFast 下 builder 已被 poison
    }
}
fullDesc, err := full.Build()
// 成功边界 = 临时目录原子 rename 到最终代目录

Cumulative delta

goevery 5 min
delta, err := be_indexer.NewDeltaIndexBuilder(be_indexer.DeltaIndexBuildOptions{
    Root:                   "/data/index",
    Generation:             202407010001,
    FromWatermarkExclusive: 100,
    ToWatermarkInclusive:   110,
    Fields:                 fields,
    MaxMutations:           1_000_000,
    FailMode:               builder.FailFast,
})
if err != nil { return err }
defer delta.Close()

for _, m := range mutations {
    if err := delta.AddMutation(m); err != nil { return err }
}
deltaDesc, err := delta.Build()
// → segment-*.bei + changed_docs.bin + deleted_docs.bin
!

Delta 必须累计。假设 full 截止 100，第一轮 delta 覆盖 (100,110]；下一轮应构建 (100,120] 并替换上一轮。只用 (110,120] 会丢失前一轮变更，也不满足 Manifest 的连续性校验。

06 · 发布与加载

gomanifest → CURRENT
m, err := be_indexer.NewSnapshotManifest(be_indexer.SnapshotManifestRequest{
    IndexName:  "targeting",
    Generation: 202407010001,
    Fields:     fields,
    Full:       fullDesc,
    Deltas:     []be_indexer.DeltaIndexDescriptor{deltaDesc},
})
if err != nil { return err }

if err := be_indexer.PublishManifest(
    "/data/index", "manifest-202407010001.json", m,
); err != nil {
    return err
}
// → 写入 manifests/，再原子切换 CURRENT
加载mmap
engine, err := be_indexer.OpenIndex(
  "/data/index", fields,
  be_indexer.LoaderOptions{
    SegmentLoad: be_indexer.SegmentLoadMmapVerify,
  },
)
defer engine.Close()
res, err := engine.Retrieve(assignments)
常驻 Holderlive
holder, err := be_indexer.NewIndexHolder(
  "/data/index", fields,
  be_indexer.LoaderOptions{
    SegmentLoad: be_indexer.SegmentLoadMmapVerify,
  },
)
defer holder.Close()

res, err := holder.Retrieve(assignments)
发布约束行为
watermark 连续Full → delta[0] → delta[1] 不允许断档；Manifest.Validate 强制校验
同名 manifest不可覆盖，返回 ErrManifestExists；每代用新文件名
CURRENT 切换临时文件 + rename 原子切换；回滚 = 指回旧 manifest
代目录 / manifest发布后不可变；不原地修改线上文件

07 · 热更新：加载失败，旧快照继续服务

goreload on manifest change
holder, err := be_indexer.NewIndexHolder("/data/index", fields,
    be_indexer.LoaderOptions{SegmentLoad: be_indexer.SegmentLoadMmapVerify})
if err != nil { return err }
defer holder.Close()

// 收到 manifest 更新通知后：
if err := holder.Reload(); err != nil {
    // 记录告警即可；旧快照继续服务。
}

res, err := holder.Retrieve(assignments)
  • 每进程一个 Holder 单例即可。引擎与快照不可变，Retrieve 并发安全。
  • CURRENT 未变化时 Reload 是 no-op，不会重新 mmap。
  • 旧快照按引用计数回收。在途查询继续持有旧 mmap，最后一个查询结束后才 unmap。
  • 不要跨 Reload 持有 UnsafeCurrent() 返回的引擎；它仅供诊断。

Reload 成功

  • 新查询立即使用新快照
  • 在途查询继续读旧快照
  • 旧 mmap 引用归零后释放

Reload 失败

  • 关闭已创建的新 Engine/Reader
  • 当前快照完全不受影响
  • 记录告警并等待下一次通知

08 · Top K：独立分数快照

goscore sidecar
// ids 按 signed DocID 严格递增，values 一一对应。
scores, err := be_indexer.NewBlockMaxScoreTable(ids, values)
if err != nil {
    return err // 构建失败时保留已发布的旧分数
}
holder.SetScoreSource(scores)

ranked, err := holder.RetrieveTopK(assignments, 100, nil)
// ranked 按 score 降序、同分 signed DocID 升序
默认缺分zero

缺失分数按 0 分竞争。阈值不高于 0 时区间剪枝保守停用，保证负分、缺分、零分平局不漏。

缺分排除skip

MissingScoreSkip 让缺分文档不进入结果，可能返回不足 N 个。每次查询固定一份 snapshot。

索引 Reload 不会清空分数；分数刷新不需要重建 Segment。对命中极少或上界不易剪枝的查询，可传 WithScorePruning(false) 使用普通布尔跳转，结果仍是精确 Top K。

09 · 可观测性：把“无匹配”和“字段错误”分开

goretrieve observer
type obs struct{ matches int }

func (o *obs) OnRetrieveStart(ctx *be_indexer.RetrieveContext) {}
func (o *obs) OnRetrieveEnd(ctx *be_indexer.RetrieveContext)   {}
func (o *obs) OnConjunctionMatch(docID be_indexer.DocID,
    conjID be_indexer.ConjID) { o.matches++ }
func (o *obs) OnExcludeSkip(docID be_indexer.DocID) {}
func (o *obs) OnCursorInit(fieldCount int)          {}

res, err := engine.Retrieve(assignments,
    be_indexer.WithObserver(&obs{}))

实现 core.FieldErrorObserver 还能收到 OnFieldError。建议至少采集：命中数、耗时、被跳过的字段错误数、exclude skip 次数。核心检索改动上线前，用原始规则逐条求值做 Shadow Testing，保证随机查询结果 100% 一致。

10 · 反模式：上线前逐条排除

反模式后果
长期持有 BooleanEngine，不走 Holder无法热更新，旧 mmap 无法及时回收
用大 delta 代替全量重建delta 全内存累积；MaxMutations 就是拦这个
换新 DocID 表达更新，或 Version 不单调旧规则残留或新规则被遮蔽
同名 manifest 反复覆盖 / watermark 断档发布或加载失败
同字段两个 Include；指望 Exclude 处理字段缺失构建失败或静默漏召回
生产用 MmapTrustPublished 但发布链未可信校验跳过整文件哈希，数据完整性风险
查询字段拼错后依赖报错未知字段被静默忽略，漏召回
热路径重复分配 collector / 拼临时结构抵消零拷贝收益
Schema 改了却沿用旧 delta / 旧 fullschema hash mismatch，加载失败
